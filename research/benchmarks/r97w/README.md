# R97W — bounded learning/forgetting research result

This directory contains the original `result.json` and
`slow_state_checkpoint.json` from the recorded R97W experiment. Their bytes
are unchanged. Their original source, `FROZEN_SPEC.json`, and `dev_frozen.json`
reference the author's historical multi-project local environment. Those
originals have deliberately **not** been published in this portable subset.

Consequently, **the original R97W benchmark is not yet reproducible from this
repository alone**. The result is provided as historical evidence, not as an
independently reproducible qualification. A portable benchmark must be separately
adapted and rerun, with a new version and evidence record; never relabel a
changed specification as the original frozen test.

The reported disposition is bounded post-forgetting meta-learning utility,
not universal FFN superiority or autonomous self-improvement.
